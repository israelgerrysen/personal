# Input data and licensing

`football.csv` is included as input for the CSV clustering example. The project repository does not currently record the dataset's original source, copyright holder, or redistribution terms.

The root MIT license applies to the project's original code; it does not grant rights to this dataset. Before redistributing the CSV, identify its source and applicable license or permission, preserve any required attribution, and record that information here. If the group cannot establish redistribution rights, replace the file with data it is authorized to share.
